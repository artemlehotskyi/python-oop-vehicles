# 🚗 Система транспортних засобів (OOP in Python)

[![Python Version](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org)
[![OOP Paradigm](https://img.shields.io/badge/paradigm-OOP-green.svg)](https://en.wikipedia.org/wiki/Object-oriented_programming)

## 📌 Опис проєкту

Цей проєкт є практичною демонстрацією ключових концепцій **об'єктно-орієнтованого програмування (ООП)** у мові Python. 

У межах завдання було реалізовано базовий клас `Vehicle` та три його спадкоємці: `Car`, `Truck` та `Motorcycle`. Кожен із цих класів має унікальні атрибути та специфічну поведінку, що дозволяє гнучко моделювати транспортну систему.

---

## 🧠 Використані принципи ООП

Проєкт ілюструє три фундаментальні стовпи об'єктно-орієнтованого програмування:

### 1. Наслідування (Inheritance)
Усі специфічні типи транспорту успадковують базові властивості та методи від головного класу, що забезпечує перевикористання коду та чисту архітектуру.
* **Базовий клас:** `Vehicle`
* **Похідні класи:** `Car`, `Truck`, `Motorcycle`

### 2. Перевизначення методів (Method Overriding)
Метод `start_engine()` задекларований у базовому класі, проте кожен похідний клас перевизначає його, щоб відобразити унікальну логіку запуску двигуна для конкретного типу транспорту.

### 3. Поліморфізм (Polymorphism)
Єдиний інтерфейс (виклик методу `start_engine()`) працює по-різному залежно від того, об'єктом якого саме класу він є:
* `Car` ➔ Запуск двигуна легкового автомобіля.
* `Truck` ➔ Запуск потужного двигуна вантажівки.
* `Motorcycle` ➔ Запуск динамічного двигуна мотоцикла.

## ⚙️ Функціонал та архітектура класів

Для наочності характеристики та можливості кожного класу згруповані у таблицю:

| Клас | Специфічні атрибути | Унікальні методи | Опис поведінки |
| :--- | :--- | :--- | :--- |
| **🚗 Car** | `кількість дверей`, `кількість пасажирів` | `drive()` | Імітує рух легкового авто |
| **🚛 Truck** | `вантажопідйомність`, `буксирувальна здатність` | `haul()` | Імітує перевезення важкого вантажу |
| **🏍 Motorcycle** | `кількість коліс`, `наявність бокового причепа` | `ride()` | Імітує динамічну поїздку на мотоциклі |
